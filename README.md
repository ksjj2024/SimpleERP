# SimpleERP - 单机ERP系统

一个功能齐全的 Android 单机 ERP 应用。

## 功能模块

- ✅ **商品管理** - 商品信息维护、分类管理
- ✅ **客户管理** - 客户信息、联系方式管理
- ✅ **供应商管理** - 供应商信息维护
- ✅ **采购管理** - 采购订单、入库管理
- ✅ **销售管理** - 销售订单、收款跟踪
- ✅ **库存管理** - 库存查询、低库存预警
- ✅ **财务管理** - 账户管理、收支流水
- ✅ **生产管理** - 生产订单、进度跟踪
- ✅ **报表统计** - 销售/采购/财务/库存报表，支持导出

## 技术栈

- **语言**: Kotlin
- **UI**: Jetpack Compose + Material 3
- **数据库**: Room (SQLite)
- **架构**: MVVM
- **导出**: Apache POI (Excel) + iText (PDF)

## 编译

```bash
./gradlew assembleDebug
```

## 下载 APK

1. 点击 Actions 标签
2. 选择最新的构建
3. 在 Artifacts 中下载 app-debug 或 app-release
